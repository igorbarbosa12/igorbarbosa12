## 👋 Sobre mim

Me chamo **Igor Medeiros Barbosa**, sou desenvolvedor web e estudante de **Análise e Desenvolvimento de Sistemas (ADS)** em Santarém – PA.

Crio sites para negócios locais: cardápios digitais com pedido pelo WhatsApp, catálogos de loja e painéis administrativos. Também faço parte do time de front-end de um sistema de gestão de vilas, feito em equipe com React e TypeScript.
